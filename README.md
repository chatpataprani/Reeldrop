## Overview

Reeldrop is an Android application for downloading video and audio from websites supported by [yt-dlp](https://github.com/yt-dlp/yt-dlp).

The project is based on the open-source [Seal](https://github.com/JunkFood02/Seal) codebase and has been rebranded and adapted for Reeldrop.

## Features

- Video and audio downloads through yt-dlp
- Playlist support
- Audio extraction
- Thumbnail and metadata support
- Subtitle downloads
- Download queue and history
- Cookie support for sites that require authentication
- Proxy and IPv4 options
- Custom yt-dlp command templates
- Android share-to-download support
- Material 3 interface

## Build

Clone the repository and build the debug APK:

```bash
git clone https://github.com/chatpataprani/Reeldrop.git
cd Reeldrop
./gradlew assembleDebug
```

You can also trigger the GitHub Actions workflow manually from the **Actions** tab.
