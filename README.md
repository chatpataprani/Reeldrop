# yawr.

> your lowkey download sidekick. paste a link, hit download, done. no unnecessary drama.

## what it does

- 🎬 downloads supported videos
- 🎵 grabs audio when available
- 📚 handles playlists
- 🖼️ keeps thumbnails and metadata when supported
- 💬 subtitles support
- ⚡ optional aria2c support
- 🍪 cookie support for sites that need login
- 📥 download history + queue management
- 🎨 clean Material 3 Android UI
- 🔗 share a link straight into yawr
- 🌐 network/proxy controls
- 😭 occasionally reminds you to actually use the app

## download

Grab the latest APK from the repository releases, or build it yourself.

## build it

### you need

- Android Studio
- JDK 21
- Android SDK
- Git

### clone

    git clone https://github.com/chatpataprani/Reeldrop.git
    cd Reeldrop

### build

    ./gradlew assembleDebug

APK output:

    app/build/outputs/apk/
