# Reeldrop\n\nReeldrop is a rebranded Android video/audio downloader based on the open-source Seal project and yt-dlp.\n\n## Features\n\n- Download video and audio from yt-dlp-supported sites\n- Playlist downloads\n- Audio extraction and metadata/thumbnail embedding\n- Subtitle support\n- Custom yt-dlp command templates\n- Download queue/history and settings\n- Material 3 interface\n- Android share-target support\n\n## Attribution\n\nThis project is derived from Seal by JunkFood02.
